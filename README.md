### 🌐 Network Log Analysis System

C++ project focused on data structures, algorithms, and network log processing.

**Tech:** C++ · STL · Manual Memory Management

- Hash tables with separate chaining for average-case `O(1)` IP lookups
- Binary search tree for ranking high-frequency addresses
- Custom linked lists with dynamic memory allocation
- Merge sort for log datasets
- BFS / DFS using adjacency matrices
- Detection of potential DDoS-like traffic anomalies

> Built to strengthen practical understanding of data structures and algorithmic complexity.
